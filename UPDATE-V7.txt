MIKROTIK SHORTCUT DASHBOARD - UPDATE V7

Perubahan:
1. Pengelolaan/input link Shortcut dipindahkan ke menu Pengaturan.
2. Halaman Shortcut hanya menampilkan shortcut yang tersimpan.
3. Tombol Kick ditambahkan pada setiap sesi PPPoE Online.
4. Traffic Download/Upload per pelanggan PPPoE ditampilkan dalam Kbps/Mbps.
5. Data traffic PPPoE dihitung dari perubahan counter interface dinamis dan diperbarui mengikuti refresh dashboard setiap 5 detik.

PENTING UNTUK FITUR KICK:
Akun API MikroTik harus memiliki kebijakan write selain read dan api.
Contoh jika grup API dashboard bernama dashboard-api:
  /user group set [find name="dashboard-api"] policy=read,write,api
Sesuaikan nama grup dengan konfigurasi router Anda. Berikan hak write hanya kepada akun dashboard yang dipercaya karena hak ini memungkinkan perubahan konfigurasi.

CATATAN TRAFFIC:
Traffic per pelanggan dibaca dari counter interface PPPoE dinamis RouterOS. Jika interface dinamis tidak ditemukan untuk suatu sesi, dashboard menampilkan tanda —. Pembacaan pertama menjadi baseline; nilai kecepatan muncul setelah interval refresh berikutnya.

INSTALASI:
1. Backup folder aplikasi dan data/config.json.
2. Extract ZIP V7.
3. Upload/overwrite file aplikasi dengan isi ZIP.
4. Jangan hapus atau timpa data/config.json agar router, shortcut, dan branding tetap tersimpan.
5. Hard refresh browser (Ctrl+Shift+R).

Tidak ada perubahan format data/config.json.
